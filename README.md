# Diseño página web cliente – Marinera (Alis Marinera)

Página web de venta de faldas y trajes de marinera para **Alis Marinera**, confeccionados por **Creaciones Brayman – Industria Textil** (La Victoria, Lima).

- `index.html`: la página. Las fotos están en la carpeta `img/` (WEBP livianos).
- `img/compartir.jpg`: imagen que aparece al compartir el link por WhatsApp o Facebook.
- Catálogo editable en el arreglo `PRODUCTOS` dentro del `<script>`: nombre, tipo, tela, descripción, colores, tallas, precio y foto.
- Ventana de detalle por producto, filtros por tipo y tela, galería con visor y menú para celular.
- Pedidos por WhatsApp (933 899 119) con el modelo y la talla elegidos.
- Paleta cálida y clara con la pluma de pavo real como sello visual.

En línea: https://bryantb22.github.io/diseno-pagina-web-cliente-marinera/
